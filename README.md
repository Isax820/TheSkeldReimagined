# 🚀 The Skeld Reimagined — Custom Map Project

## 🎮 Presentation of the project

**The Skeld Reimagined** is a project to create a **custom Among Us map** inspired by the famous map **The Skeld**.

The goal of the project is to completely recreate the map with:

* 🏗️ New areas
* 🎨 Personalized artistic direction
* ⚡ New mechanics
* 🔥 A more immersive atmosphere
* 🧩 Unique events and interactions

Development is carried out using the **Level Impostor** mod, allowing the creation of personalized maps in *Among Us*.

## ✨ Objectives

The project aims to offer an experience different from the original map:

| Feature | Description |
| ---------------------------- | ------------------------------------------------- |
| 🗺️ New layout | Some rooms will be moved or redesigned |
| 🔐 Interactive systems | Doors, events, animations and dynamic elements |
| 👀 Improved Gameplay | New passages and possible strategies |
| 🎵 Immersive atmosphere | Personalized sounds, lights and decor |
| ⚙️ Multiplayer compatibility | Playable with other players via mod |

# 🌐 INSTALLATION TUTORIAL

- 1 Download the correct ZIP version based on your Among Us version (in [release](https://github.com/Isax820/TheSkeldReimagined#release))

- 2 Access the folder where Among Us is installed: 
- Steam: `C:\Program Files (x86)\Steam\steamapps\common\Among Us` 
- Epic Games: `C:\Program Files\Epic Games\AmongUs`

- 3 Extract the downloaded files there. Make sure the folder is in the same folder as the file (see screenshot below). BepInExAmong Us.exe

- 4 Launch the game (please note that the first launch may take some time)

⚠️ Alternatively, if you already use other mods or have BepInEx installed, you can download the DLL file directly and place it in .BepInEx/plugins
